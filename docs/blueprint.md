# **App Name**: Zenith CRM Lite

## Core Features:

- Dashboard & Navigation: A dashboard with widgets showing relevant KPIs, a quick access menu, activity feed, and global search, accessible on all devices.
- Customer Management: Customer management functionality with contact records, organization profiles, status tracking, interaction history, and notes & tags.
- Sales Pipeline: Simple sales pipeline with deal tracking, win/loss analysis, and follow-up reminders.
- Task Management: Task management with personal task list, calendar integration, automated reminders, and team task assignment.
- Account Management: Account registration system which automatically makes the registering user an admin of their own organization and allows them to manage team members under the same organization.
- Team Member Management: Team member management with user creation, password handling, password security measures, and simple role-based permissions.
- Stripe Integration: Stripe integration to handle subscription payments of 6.99 EUR/month per user.

## Style Guidelines:

- White and Blue color scheme for the user interface.
- Modern sans-serif typography for optimal readability.
- Simplified design with a clean and intuitive interface, prioritizing ease of use.
- Accent: A subtle green (#90EE90) to highlight important actions and notifications.
